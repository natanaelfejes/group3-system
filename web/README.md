# web

React + TypeScript frontend, created with Vite. The page is still the Vite starter, replace it.

```bash
npm install
npm run dev      # dev server with hot reload, http://localhost:5173
npm run build    # type-check + production build into dist/
npm run lint
```

`docker compose up --build` from the repo root serves the production build with nginx on http://localhost:3000.
